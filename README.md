# Windows-Cleaner
You can run commands for cleaning windows file[e.g  temp, %temp%, prefetch and others.....]

How to use it

  1. Open Notepad.
  2. Paste the script.
  3. File → Save As
  4. Name it: --> WindowsCleanup.bat   [Important Step]
  5. Change Save as type to: All Files
  6. Right-click the .bat → Run as administrator.

Note: If u won't save the script as file_name.bat [*.bat] then windows will recognize it as a .txt file and only notepad will open.
